# 百草源 · HERB ORIGIN

本草文化与自然观察学习的原生微信小程序。界面采用草木绿 `#244b3b`、浅灰纸面 `#f6f7f4`、白色内容面与细分隔线，以“探索—学习—记录”组织四个底部入口。页面使用统一线性 SVG 图标、小圆角和系统字体，保留原生返回、触控反馈与低动效支持。设计说明见 [扁平化界面更新](docs/FLAT_UI_UPDATE.md)。

## 本轮更新 · 1.3

- 首页、顶部栏、搜索框、内容列表与个人中心统一为扁平化样式，去除背景渐变、磨砂与投影；页面图标改为可变色 SVG，原生底部标签栏保留 PNG。详情页展示累计浏览、今日浏览、获赞和被收藏四项统计。
- 笔记列表支持快捷点赞、收藏、选中状态与操作加载反馈；取消收藏或点赞后立即从对应列表移除，翻页去重并保持正确加载位置。
- 点赞与笔记收藏提交明确目标状态，重复点击、响应丢失后的重试不反转状态或重复累加；浏览日期在服务端事务执行时计算，避免排队跨北京时间零点记入旧日期。正式账号需重新部署 `community` 云函数以启用目标状态处理。
- 首页直接搜索，最近六条阅读按游客、体验与正式账号分别保存；“继续学习”直接打开首个未完成章节。
- 探索的古籍分类可单独清除；课程正文展示目标、步骤、练习与自查，学习进度保存失败可重试。
- 游客与正式账号均有本机私密手记入口；恢复到账号本机库的记录可阅读、编辑、删除，上传须自主选择。
- “我的”可导出及恢复 JSON 备份，支持文件与剪贴板。先校验再合并，重复去重、冲突保留副本；多模块部分写入失败会说明完成范围，重试不重复增加记录。
- 注册新增可阅读的用户协议、隐私说明与默认未勾选的同意项。个人资料和公开笔记通过微信文本安全检查；检查不可用时不发布并保留草稿。公开笔记可举报，运营方从私有集合处理。
- 正式账号使用文字头像；本机体验保留图片头像。云端图片头像待媒体安全流程完成后再开放。
- `config.serviceMode = 'local'` 提供本机学习备用版本，停止该构建的云调用；课程、精选笔记、互动学习、本机记录和备份仍可使用。

正式上线前需部署本轮云函数，填写实际运营主体与有效联系邮箱，并完成平台隐私配置、举报处置和真机验收。参赛资格和上线时间核验见 [发布与备用方案](docs/RELEASE_PLAN.md)，本次实际验证见 [优化验收报告](docs/OPTIMIZATION_REPORT.md)。用户反馈当前未上线；源码、编译及模拟器通过不代表已正式上线。

## 运行

在微信开发者工具中导入本项目根目录 `D:\WXproject\miniprogram-3`，点击“编译”。小程序源码目录为 `miniprogram/`。保留原项目 AppID，基础库使用 3.17.3；本地体验不需要开通云环境、安装 npm 组件或配置服务器。

主页面：首页、探索、笔记、我的。二级页面：统一内容详情、草木游学场、笔记阅读与编辑、注册登录、资料编辑、关于百草源、用户协议与隐私说明。启动页为 `pages/index/index`。公共课程、官方笔记和游学场无需注册，内容随主包提供。在“我的”或登录页点击“进入本机体验”，无需注册、密码或云服务，即可体验笔记、互动和个人资料。正式账号、笔记上传及跨用户互动需要配置云开发环境并部署新增的 `community` 云函数，步骤见 [社区部署说明](docs/COMMUNITY_SETUP.md)。

## 已实现

- 首页：菊花观察主视觉、四类入口、免费课程横向列表、四种游学体验入口和官方笔记预览。
- 探索：本草档案覆盖《本草纲目》四库全书本药物正文卷五至卷五十二、16 部、62 个检索分类；1886 条目录与附录档案，支持原名、简繁名称、历史别名、部类筛选与“仅看植物部类”。每次加载 20 条。
- 内容详情：档案提供原名、卷次、出处与原文分段阅读，可阅读本卷完整校录原文（含目录、上下卷及附属药物）。提供九门免费课程、十二篇官方公共笔记和四条自主观察路线，内容含具体步骤、学习示例和记录模板，并关联延伸阅读。
- 课程：三十二个章节，涵盖观察、手作、四季记录、古籍阅读、摄影、叶片形态、长期观察、拼贴和公共写作。展示目标、材料、动手练习与自查；保留原八个章节 ID 和旧进度，定位第一节未完成章节，已完成课程可重读。
- 草木游学场：知识闯关（六主题三十题，每轮五题、即时解析、关联课程）、术语翻牌（十二组词汇中随机抽六组配对）、七日观察（七个任务，按北京时间每个日期一条真实记录，当天可修改）、每日灵感卡（十四个提示，同一天保持一致）。成绩、观察和六枚学习徽章按游客、演示及正式账号在本机独立保存；写入失败可重试，失败不解锁徽章。
- 官方公共笔记：公共页预览与可搜索的“官方精选”列表，社区加载失败仍可阅读。官方内容不计入用户社区笔记数；模板默认私密，确认后可继续原有草稿或使用新模板。
- 收藏：游客可以收藏和取消；首页、探索、详情和个人中心重新展示时同步本机记录。
- 笔记：我的、公共、收藏、点赞、本机手记和精选分类；独立阅读页、创建、编辑、删除确认、关联阅读、自动本机草稿与离开提示；标题最多 80 字，正文最多 10000 字。
- 可见范围：新笔记默认私密。登录后可私密上传或公开分享；公共笔记可供其他用户浏览、点赞和收藏。改为私密后，其他用户的收藏与点赞列表立即不再展示该内容。旧本机手记逐篇显式上传，并保留原手记。
- 浏览统计：详情正文显示后才提交浏览，同一微信用户每天计一次，作者本人不计数。笔记列表与详情显示累计、今日浏览，“我的”汇总自己笔记的累计和今日浏览；列表、详情支持下拉刷新。同一页面跨北京时间零点返回或刷新可重新计数。统计写入失败保持正文可读，单独重试沿用原阅读标识；迟到的计数和点赞响应不会互相覆盖。
- 账号：用学号、手机号、用户名与密码注册，学号或手机号加密码登录；服务端加盐 scrypt 密码摘要、绑定微信用户的过期会话，禁止客户端直接读取账号和笔记数据库。
- 官方演示：一键进入本机演示账号，预置私密、公共与官方示例笔记，可创建、编辑、删除自己的笔记，体验浏览计数、点赞、收藏、资料和头像修改，以及内容收藏、课程进度和笔记导出。演示公共内容只在当前设备的演示列表展示，退出后保留；游客、演示和正式账号记录各自隔离。页面明确标记演示，真实跨用户分享需切换正式账号。
- 资料：可修改用户名、个性标签与简介；正式账号头像取用户名中的首个汉字或字母，字母大写。本机体验可选择图片头像。
- 我的：内容收藏、进行中的课程、已完成课程、我的笔记、收藏笔记与点赞笔记可直接进入对应列表；云端笔记浏览、获赞、被收藏统计同步展示；学习中与已完成不重复计数。
- 导航：统一传递模块范围与关联内容，明确入口清空旧筛选；相关笔记统计和跳转对应同一数据来源，账户切换不会沿用前一个账户的迟到响应。
- 关于：古籍版本与收录口径、校录缺文说明、文字许可、本地数据说明、图片署名与出处。

## 数据和扩展入口

`miniprogram/data/catalog.js` 是公共内容入口。`archive-index.js` 保存轻量目录，`archive-catalog.js` 提供分页、筛选与异步详情；`corpus01` 至 `corpus03` 保存全卷原文，通过微信 `require.async` 按需下载，首次阅读资料包需要网络。药物 ID 按来源卷次和原名生成，原 `h1/h2/h3`、课程和章节 ID 保持兼容。`public-learning.js` 保存公共课程、官方笔记和路线，`play-content.js` 保存题库、词汇、观察任务和灵感卡，`learning-catalog.js` 组合兼容目录。扩充内容与来源见 [公共学习说明](docs/PUBLIC_LEARNING.md)。

档案条目数不等同原书药物种数：一条可能含多种药物、部位与附录。12 条目录名称未定位独立正文或原校录标有缺文，详情明确提示，仍可检索原名并阅读整卷。原文不是现代用药知识库。数据来源、原始快照、固定修订号、校录限制和重建命令见 [古籍数据说明](docs/BENCAO_SOURCES.md)。

`miniprogram/services/store.js` 负责本机记录与校验；页面无需直接写 journal。`services/community.js` 负责会话及真实云端请求，演示模式调用 `services/demo.js` 的本机适配器；`services/navigation.js` 负责页面跳转，`cloudfunctions/community` 负责真实社区账户权限、笔记、互动与统计。

游客记录保存键为 `herb-origin:journal:v1`，包含版本、收藏、课程完成集合和带 ISO 时间戳的本机手记；登录后内容收藏和课程进度以用户 ID 分开保存，不自动继承游客数据。草稿键为 `herb-origin:note-draft`，登录后附用户 ID。所有写入成功后才更新界面；存储失败不显示保存成功，也不推进章节。新建云笔记携带稳定创建标识，重试或恢复同一草稿不会重复创建。

演示笔记、资料、互动和持久化头像路径保存在 `herb-origin:official-demo:v1`；演示学习记录使用用户范围 `demo-official`。会话只保存 `{mode: 'demo'}` 标记，不保存公共账号密码或虚假云端令牌。演示读写不调用云函数，失败不会回退到真实社区；正式登录失败仍可继续演示。头像保存到微信本机文件目录，最大 2 MB。演示笔记导出只包含自己的笔记正文和可见范围，不包含其他作者示例、账户凭据或头像文件。

游学记录使用 `herb-origin:play:v1:<用户范围>`，包含答题与配对成绩、观察正文、已打开灵感卡的日期。范围为 `guest`、`demo-official` 或正式用户 ID。导出 JSON 的 `state.play` 包含当前范围的游学记录。模板只通过五分钟有效、绑定账号的一次性内存标识传递，正文不进入页面 URL；进入编辑页不会覆盖未确认的已有草稿。

云端资料、笔记和笔记互动可在登录同一账户后跨设备读取；内容收藏、课程进度、未保存草稿与本机手记仍是本机记录。JSON 备份排除密码和登录凭据，包含当前身份的本机学习数据与自己的体验笔记；不包含云端笔记、未保存草稿、头像和最近阅读。新版备份只恢复到原身份范围，旧版缺少身份标记的备份会提示来源无法核验；不会自动切换账号、上传或公开。换机或清理缓存前请导出并保存备份，随后从“我的”恢复。浏览次数按北京时间自然日统计，同一微信用户同一笔记一天最多计一次，作者本人阅读不计入；点赞与收藏按账号去重。课程预计分钟数是阅读参考值。文化路线提供参观方法，不包含预约、带队或交易。

原 quickstart 示例和云函数仍保留在工作区，但不进入当前页面路由和发布资源；应用启动不调用其云函数。新增 `community` 云函数需要单独部署。原入口文件备份在 `.codex/reference/quickstart/`。

图标生成：`pwsh -File scripts/generate-icons.ps1`。图片出处与许可见 `docs/ASSETS.md`。
