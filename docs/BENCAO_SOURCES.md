# 《本草纲目》档案来源与收录口径

版本：李时珍《本草纲目》四库全书本。来源为[维基文库该版本](https://zh.wikisource.org/wiki/本草綱目_(四庫全書本))的 MediaWiki 修订 API；下载时间 2026 年 10 月 8 日，总目录固定修订号 2709777。没有使用未核实的药名清单，也没有为凑齐“1892”生成条目。

收录药物正文卷五至卷五十二，共 48 卷，含 12、17、18、35、50、51 六卷的上下篇，合计 60 个来源页面。序例、百病主治药和图卷不作为本次药物档案正文。原书包含水、火、土、金石、草、谷、菜、果、木、服器、虫、鳞、介、禽、兽、人 16 部；植物筛选依原书草、谷、菜、果、木五部划分，包含原书置于这些部类的菌类。

目前生成 1886 条检索档案：1820 个目录名称与 66 条目录只统称“附录诸石／诸藤／诸木”的具体名称。收录类型为 1635 条目录正条、153 条有名未用、98 条附录。卷 38 目录重复出现的“灯盏”合并为一个检索入口，完整原卷两处文字均保留。名称统一入口不等同现代药材物种鉴定；单条内的附属品种、药用部位仍随该条及整卷原文保留。

原书总目自身写有 1882 种，而凡例说明以正名为纲，将多种名称和部位附列其下。因此本应用展示实际档案条数，不把它宣称为“1892 种独立药材”。本次完整转录原文的覆盖范围与检索条目计数是两个口径。

原文保留繁体与历史观点。仅展开 SK anchor / SK notes / SKchar 模板、去除网页导航标记和多余空白，使用维基文库官方字形模块映射可辨异体字；未辨字保留明确标记。简体名称、繁简检索映射与“释名”中的关联名称只用于查找。生成器中的目录—正文对应关系处理该校录本的异写或错字，不改动原文。鱼类、龟鳖类等受损目录标题与同一来源的总目录比对后用于分类；未改写正文药性、方剂或剂量。

12 条目录名称在所用校录中缺文或未定位独立正文，详见审计 JSON 的 `unmatched`。它们仍是可检索档案，详情显示校录说明与完整原卷入口；没有借其他版本文字填充，也没有生成医疗内容。来源本身尚未逐字精校，少量标点、缺字和标题错误可能仍在。原文历史方剂不作为现代诊疗、配药或采食依据。

证据和可复现文件：

- `bencao-source-manifest.json`：60 个页面的原址、固定修订号、下载时间、原始内容 SHA-256 和包内规范化文本 SHA-256。
- `bencao-source-snapshot.zip`：原始 Wikitext、来源目录与两个官方异体字模块；用于离线重建。
- `bencao-extraction-audit.json`：逐卷目录计数、部类、收录类型、重名合并和未定位条目。
- `scripts/build-bencao.py`：正文与索引生成器。索引的范围使用 JavaScript UTF-16 单位，避免罕见汉字导致正文截取错位。

重建需 Python 3.9 或更新版本及 `opencc-python-reimplemented`。在项目根目录运行 `python scripts/build-bencao.py`；若 `.codex/bencao-reference` 不存在，会从随附 ZIP 恢复。也可传入包含 `manifest.json`、`raw/` 的快照目录。应用运行无需 Python 或 npm 组件。

包内全文分成三个异步 JS 资料包，主包只载入目录；字形映射、目录原名与来源文本均随应用打包。完整原卷入口还包含目录，拆分卷会同时读取目录、上篇、下篇。
