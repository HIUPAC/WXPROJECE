# 百草源参赛发布与备用方案

本方案记录本次实现的发布路径和验收依据。文档、自动化测试通过或开发者工具预览都不能代替微信公众平台的正式发布和微信真机验证。编写日期：2026 年 10 月 11 日（北京时间）。

## 参赛资格与必须保留的证据

根据用户提供的本次比赛条件，命题不限；作品需遵循微信小程序设计指南及平台运营规范；需在 **2026 年 7 月 17 日至 10 月 17 日** 提报阶段内通过微信公众平台正式上线，并能在微信内正常运行。7 月 17 日前已提报参赛信息，或此前已上线/运营的作品，不属于用户描述的本次参赛范围。

本次本地代码检查不能确认该 AppID 的历史上线时间、参赛提报时间、审核状态、主体资格或真实云环境部署状态。应由有权访问微信公众平台和赛事系统的负责人逐项核实，不能把本次更新版本当作首次上线证明。

用户于本次沟通中确认作品“未上线”。当前按首次正式上线待完成安排；该反馈不能代替平台历史记录、此前运营情况或赛事提报回执，其他资格证据仍需核实。

## 主方案：知识学习与真实云笔记社区

将 `miniprogram/config.js` 的 `serviceMode` 配置为 `community`，确认 `cloudEnv`、`communityFunction` 与实际可访问环境一致。核心路径为：首页进入课程/本草档案 → 学习章节/收藏 → 写观察笔记 → 自主选择私密或公开 → 在笔记与我的页面查看结果。草木游学场提供本机知识闯关、术语配对、七日观察和每日灵感卡；其成绩、观察与学习徽章按当前账号保存在本机。

云笔记、公私范围、点赞收藏、浏览统计及云端资料由云函数提供；本机内容收藏、课程进度和游学记录独立保存，不能把它们描述为自动跨设备同步。游客本机手记和演示笔记不会自动上传。当前公开笔记及昵称/简介/标签接入文本内容检查，检查失败应拒绝提交并保留可继续编辑的内容。正式账号使用文字头像，生产服务与客户端关闭云图片头像更换；游客/演示图片头像仅保存在本机。文件类型、大小和归属校验不能代替图片内容审核。

部署按 [COMMUNITY_SETUP.md](COMMUNITY_SETUP.md) 完成：

1. 在正确 AppID 和目标云环境部署当前 `cloudfunctions/community`，使用“上传并部署：云端安装依赖”，确认运行配置与日志。
2. 创建部署文档列出的八个集合（包括 `community_reports`）并分别配置客户端拒绝直读写规则；逐条建立所需笔记索引。
3. 应用受限存储权限并核查历史文件；核实 `cloudfunctions/community/config.json` 中的 `security.msgSecCheck` 权限已随当前云函数部署，检查实际微信账号的接口调用结果。权限未就绪、接口异常或检查未通过不能降级为直接公开。确认旧客户端直接请求云头像上传也被生产服务拒绝，未来开放必须通过媒体安全接入后的审查变更。
4. 用两个真实微信用户验证注册登录、笔记私密权限、公开/撤回/删除、统计去重及云图片头像上传被拒绝。演示模式的本机结果不能作为跨用户验证证据。
5. 后台实际类目、简介、截图和审核说明与已实现功能保持一致；需要的主体或类目资质由平台负责人核对。

## 备用方案：明确标识的本机学习版本

备用版本将 `miniprogram/config.js` 中的 `serviceMode` 改为 `local`，重新构建、验收和按微信公众平台流程发布。该配置停止云初始化与社区请求，保留知识内容、课程、收藏、游客手记、官方演示与游学场。演示账号、公共演示列表、资料和互动仅保存在当前设备，页面必须明确标识其范围。

这一方案适用于云部署延期、内容安全接入未通过验收或服务不可恢复时。功能介绍与审核材料应同步删除真实云社区/跨设备能力的承诺；不把本机保存显示成“云端已同步”，也不把演示互动显示成真实用户数据。启用备用方案仍需正式平台发布和微信正常运行，并不能绕过比赛上线时限或主体审核。

当前 `serviceMode` 是打包配置，不是远程热切换。修改配置不会即时更新已经安装的正式版，也不会关闭已部署的云函数或改变旧客户端；重新上传、审核、发布的实际时间取决于平台流程。已发布版本发生网络故障时应显示实际失败并引导用户使用仍可工作的本机功能，不能自动切换身份或把待发布的云笔记存成已同步记录。

### 故障处理操作

| 故障 | 操作 | 验收结果 |
| --- | --- | --- |
| 登录/云列表不可用 | 核对云环境和函数名，查看客户端分类日志及云函数请求 ID；确认函数已部署并安装依赖 | 正式账号可登录且两个用户互相看到允许公开的笔记 |
| 缺集合/索引/权限 | 按部署文档创建缺少的集合、单独建立索引、应用受限规则；保留私密数据的访问边界 | 私密笔记直接链接、搜索、点赞收藏均不向其他用户泄露 |
| 内容安全调用失败 | 修复权限/接口配置后重试；继续拒绝公开发布，保留编辑内容 | 合规测试文本可保存；明确被拒或调用失败的文本不能公开 |
| 无法在发布窗口内完成云方案 | 改 `serviceMode: 'local'`，同步审核资料，完整验收后上传并按平台流程正式发布 | 断网学习和本机恢复可用，所有演示和本机范围说明明确 |
| 设备存储满/读写失败 | 不清空原存储；提示实际失败，先备份可读取的记录；释放其他无关空间后重试 | 不假显示已保存，不覆盖损坏或无法读取的已有数据 |
| 新版出现回归 | 使用已留存版本回退或提交修复；云函数回退必须保留内容安全、私密权限和账号隔离闸门 | 正式版关键路径重验，原数据和安全边界保留 |

云服务修复后，原正式账号自行登录继续云功能。游客记录、其他账号记录及演示笔记不会自动搬入正式账号；如需真实分享，由用户逐篇核对内容并明确提交。

## 本机备份与恢复的实际范围

“我的 → 导出本机备份”导出当前范围的 JSON；“恢复本机备份”支持选择 JSON 文件或完整 JSON 文本。服务接口为 `services/backup.js` 的 `createBackup()` 和 `importBackup(input)`。

新导出格式为 `baicaoyuan-local-backup` v1，标记游客/正式账号/演示范围及本机笔记/演示笔记来源。新格式只允许恢复到相同账号范围；恢复不会登录、退出或切换账号。兼容旧版 v1 导出，旧文件没有账号标记，恢复前应由用户确认文件来源，服务将内容合并到当前本机范围并明确告知。含演示笔记的旧文件只能在官方演示模式恢复，官方编辑示例和其他作者的笔记不能导入。

- 只处理收藏、已完成章节、本机手记、游学记录和自己的演示笔记；不含密码、会话令牌、手机号、学号、头像、云笔记、云互动或其他账号的记录。
- 全份校验版本、字段、正文、ID、关联内容、日期、题目与答案；应用保护上限为 1 MB/1000 篇笔记。完整输入和所有目标记录校验通过后才开始写入。未知字段、无效内容或读取损坏会中止，保留原数据。
- 收藏与章节合并去重；同编号同内容笔记跳过，同编号不同内容保留独立副本。游学次数取较大值，最好成绩按规则合并，不把汇总次数相加冒充完整比赛历史。当前已有的最近一轮保留，备份中不同的答题最近一轮/配对汇总另存为本机手记，不静默丢弃。
- 观察任务或日期冲突时，保留当前观察，将备份正文转换为可查看的本机手记并说明；不替换已完成任务或虚增七日观察进度。合并灵感日期超过 366 天时中止，要求保留原文件，不静默截掉历史。
- 微信同步存储没有本服务可用的多键事务。写入逐模块确认；失败返回已确认恢复的模块和可能已经保存但无法确认的模块，界面显示实际结果。保留原 JSON 后可重试，幂等合并不会重复新增笔记、观察或次数。
- 恢复演示笔记只处理作者自己的正文及可见范围；原演示资料、头像、官方编辑文章和已有互动保留，新增的演示笔记互动从零开始。恢复不会触发向其他微信用户发布。

导出的 JSON 含手记与观察正文，分享/存放文件前由用户自行选择可信位置。无法读取的数据不能被声称已成功备份；清除微信存储前先验证备份文件可读取且账号范围正确。

## 设计、隐私与运营准备

官方 [微信小程序设计指南](https://developers.weixin.qq.com/miniprogram/design/) 强调页面重点、明确导航与及时反馈。验收时应检查首页呈现作品的核心学习功能，返回和底部入口可预测，收藏/保存/恢复等操作有实际成功或失败结果，空白、无权限、离线和不可用状态可恢复。

官方 [微信小程序平台运营规范](https://developers.weixin.qq.com/miniprogram/product/) 涉及有效开发者联系方式、核心功能呈现、实际服务与类目一致及侵权投诉机制。正式上线前需填入真实运营主体和可用联系渠道，落实投诉受理、内容下架及用户问题处理；仓库里的界面或文字说明不等于这套运营流程已经落实。

官方 [小程序隐私授权指南](https://developers.weixin.qq.com/miniprogram/dev/framework/user-privacy/PrivacyAuthorize.html) 要求后台用户隐私保护指引声明相应用户信息，并在用户同意状态满足要求后调用相关隐私接口。使用平台默认隐私弹窗或已验证的合规实现；应用内说明页不能替代后台声明或平台同意状态。

发布负责人应实际确认：

1. 注册所需学号/手机号的用途、必要性、保存范围和退出/删除渠道；本项目不提供短信验证码或学籍核验，不宣传已认证身份。
2. 头像、昵称、标签、简介、笔记、观察及文件选择等实际使用的数据与接口是否在后台准确声明；拒绝相关授权时仍有可用的知识阅读路径。
3. 文本检查覆盖公开笔记及公开资料，超时/异常按失败处理。公开云笔记举报由 `reportNote` 写入受限集合 `community_reports`，同一微信用户同日同笔记去重，理由为侵权、隐私、内容或其他；运营人员需在云控制台读取 `status: 'pending'` 并人工核实、处置及留存结果。当前没有管理员网页或完整运营工单系统，自动文本检查和提交举报均不能替代持续处置。云图片头像更换已在生产服务与客户端关闭；运营方仍应核查已有云头像的披露范围。未来开放需先实际接入媒体内容安全，不能据文件校验宣称已做图片审核或通过客户端开关绕过。
4. 知识内容与图片来源可核查，不将草木观察、知识学习描述为诊断/处方或功效保证；真机确认相关提示与路线注意事项可见。
5. 隐私说明中的开发者联系信息、数据保留期限、删除和反馈渠道为真实配置。`miniprogram/config.js` 的 `publisherName` 和 `contactEmail` 目前留空，需填真实运营主体和可用联系邮箱；其他待配置事项在上线前补齐。不能据本地通过测试自动判定“已经合规”。

## 微信真机验收清单

至少使用 iOS 和 Android 的真实微信正式版，保留设备/微信版本/作品版本/时间和结果。测试中涉及公共内容时用受控测试账号，结束后整理测试数据。

| 验收路径 | 通过标准 |
| --- | --- |
| 冷启动与四个底部入口 | 首页、探索、笔记、我的可进入并正确切换，无空白或失去返回入口 |
| 内容阅读与关联跳转 | 课程/本草/路线/公共示例可查看，分包加载、搜索、筛选及关联入口可到达 |
| 收藏、课程和游学场 | 真正保存结果，重新打开保留；五题、配对、观察和每日卡可完成；重复操作不重复记数 |
| 笔记新建、编辑、保存和删除 | 无效输入有提示；保存失败仍可修改重试；离开未保存内容有合理提示 |
| 游客、演示、正式账号切换 | 学习记录、正文和异步结果按账号隔离；演示范围明确，不误导为跨用户发布 |
| 两微信用户的云社区 | 私密不可见、公开可见、改私密/删除立即拒绝读取；点赞收藏和每日浏览去重 |
| 隐私及拒绝授权 | 实际平台弹窗和后台声明一致，拒绝后可继续知识阅读；必要操作给出可理解的反馈 |
| 备份与恢复 | 文件/文本两种入口可恢复，旧格式可辨识，错误JSON/错账号/存储失败和重复恢复结果真实 |
| 网络差、断网和云故障 | 仍可使用已经可用的本机内容；云保存失败可重试，不误标已同步 |
| 内容安全与投诉 | 测试拒绝内容/检查异常时不能公开；真实联系和受理路径可用 |
| 视觉与交互 | 刘海/小屏/大字号页面不遮挡，滚动与按钮无误触，颜色对比、加载/空态/错误反馈清楚 |
| 正式发布后复验 | 通过正式版二维码在微信进入并完成核心流程，而非体验版/开发工具通过 |
