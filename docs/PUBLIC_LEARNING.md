# 公共内容与草木游学场

本次公共内容随小程序主包提供，无需社区云函数即可阅读或游玩。入口在首页、探索和“我的”；课程详情可直接打开相应主题的五题挑战。

## 内容目录

九门课程、三十二节：本草观察（三节）、手作小袋（三节）、四季笔记（两节）、古籍阅读（四节）、手机摄影（四节）、叶片形态（四节）、长期观察（四节）、纹样拼贴（四节）、公共写作（四节）。原 `c1/c2/c3` 与八个章节 ID 保留，旧学习进度继续生效。每节包含目标、三步操作、明确标为学习用途的示例、实际练习及自查。

十二篇官方公共笔记：花的观察、陈皮纹理、叶形描述、照片说明、雨后观察条件、古籍阅读卡、无香手作、保留未观察栏、药园标牌、三视角、拼贴说明和公开发布检查。由“百草源编辑部”署名，独立展示；不会伪造注册用户、社区发帖、浏览数或点赞数。社区不可用时，官方预览和“官方精选”搜索仍能使用。

四条自主路线：药园四站、校园三站、亲子纸上和居家古籍阅读。包含准备、每站任务、成果和参考时间，不提供具体地址、预约或带队。

## 四种互动

- 知识闯关：三十道题，六个主题各五题，每轮抽五题。首次作答锁定选项，立即展示解析；完成后保存成绩并提供关联课程。重复保存同一轮不会再累加。
- 术语翻牌：十二组词汇中随机选择六组，共十二张牌。配错显示约 850 毫秒后翻回，匹配牌保留；完成后记录尝试次数和最好成绩。离开页面取消翻牌计时，返回或重开不会执行旧计时器。
- 七日观察：七个不同任务，各完成一次；按北京时间每天最多一条，允许修改今天同一任务的记录。需输入 20–500 字，未观察不得补造。历史记录只读，可整理成笔记；七个日期无需连续。
- 每日灵感卡：十四条具体行动提示，按北京时间日期确定。同一天多次打开仍为同一张；打开日期去重，保留最近 366 个日期。

六枚徽章从实际保存的学习记录计算。失败写入不增加成绩、任务或徽章，页面保留结果并支持重试。游客、演示、正式账号互相隔离，退出后数据仍在当前设备。观察正文属于个人记录，不会出现在公共列表；“整理成笔记”默认创建私密笔记，公开需在编辑页选择。

## 内容维护与来源

公共目录在 `miniprogram/data/public-learning.js`，题库和任务在 `play-content.js`；计分与存储在 `services/play.js`。教学步骤、示例、练习及题目为本项目中文编辑内容；示例不表示真实用户观察或实际物种鉴定。

植物形态、长期观察与植物绘画的基础方法参照以下机构资料，相关课程详情提供可复制链接：

- [NC State Extension：Botany](https://content.ces.ncsu.edu/extension-gardener-handbook/3-botany)
- [USA National Phenology Network：Education](https://www.usanpn.org/nn/education)
- [Royal Botanic Gardens, Kew：What is botanic art?](https://www.kew.org/read-and-watch/what-is-botanic-art)

古籍文献版本与许可沿用 [本草档案说明](BENCAO_SOURCES.md)。本内容用于观察与文化学习，历史记载与现代观察分栏，不提供诊疗、配药或采食指导。

备份通过“我的 → 导出本机备份”，当前账号游学数据位于 JSON 的 `state.play`。可在“恢复本机备份”选择 JSON 文件或完整备份文本，恢复只合并当前本机范围，不上传云端或切换账号。新备份标记账号范围，旧 v1 文件兼容但需要用户确认来源；重复恢复去重，冲突观察保留为本机手记，读写失败如实反馈并可安全重试。备份不含密码、会话或其他用户的笔记。具体限制与备用模式见 [RELEASE_PLAN.md](RELEASE_PLAN.md)。
