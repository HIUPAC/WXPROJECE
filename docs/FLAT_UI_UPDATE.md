# 扁平化界面更新 · 2026-10-29

本次调整覆盖四个主页面、共享导航/内容卡片/图标，以及内容详情、手记编辑与阅读、游学、登录、资料、关于和协议页面。

## 视觉处理

- 背景采用 `#f6f7f4`，内容面采用纯白，分隔线采用 `#e3e7e1`，轻提示底色采用 `#edf1eb`。草木绿 `#244b3b` 用于主操作、选中态与关键链接。
- 去除磨砂、渐变、投影和反光边框。常用圆角收敛至 12rpx，小标签为 4–6rpx；导航筛选改为下划线选中态。
- 首页使用原有实拍植物图和独立文字说明，四个入口横向排列。练习和精选手记使用分隔行，缩短装饰性口号。
- 探索页保留古籍名称、部类、卷次、关联名称的信息层次；结果使用紧凑列表。笔记保持作者/日期、标题、摘要、互动的阅读顺序，精选笔记改为图文列表。
- 功能标题、统计数字、表单采用系统字体；古籍名称和专属阅读标题保留宋体。正文与原生输入框保持清晰对比。

## 图标

`miniprogram/data/ui-icons.js` 为 20 种原创 SVG 图形的唯一页面图标入口。使用 24×24 画布、1.65px 线宽、圆端点和圆转角，支持实际传入的十六进制颜色。`app-icon` 生成编码后的 SVG data URI，无需图标字体或网络资源。原生底部标签栏继续使用已有透明 PNG 线条图标。

## 设计参考

- [微信官方 WeUI](https://github.com/Tencent/weui)：参考适合微信场景的导航、列表、分隔线与表单结构。
- [Lucide 图标规范](https://lucide.dev/contribute/icons/specification)：参考统一网格、线条重量和几何比例；本项目图形自行绘制，未引入外部图标库。
- [Material Design 列表](https://m3.material.io/components/lists/overview)：参考主文本、辅助说明、图像和尾部操作的一致顺序。
